The project

Build a useful bedside table, one reliable stage at a time

Use the modules in order. Read and inspect the theory, practise with guided feedback, apply the process in the workshop, then save evidence for submission.

How the course works

One predictable routine for every two-week module

Students build understanding before answering, then use feedback and model responses to improve their work.

1. Read and inspectStudy plans, theory, technical diagrams and workshop examples.
2. PractiseComplete guided knowledge checks and written responses.
3. ApplyComplete each workshop stage carefully, accurately and safely.
4. ReviewUse checks, evidence and evaluation to improve the finished table.
