BEDSIDE TABLE GUIDED COURSE – TEACHER NOTES

The course follows the same visual and interaction system as the Folding Chair Guided Course. Each two-week module contains six theory sections, twelve guided checks and four scaffolded written responses.

The supplied project drawing and current school workshop procedures remain authoritative. The website deliberately avoids inventing hardware sizes, finish products, drying times or local procedures. Any design variation, structural repair or changed fitting method requires teacher approval.

Browser storage is convenient but is not the official submission. Students should save each module as a PDF and download the folio ZIP backup.
